IT HELP DESK TICKET TRACKER - BUILD PATH

Build rule:
Move in small phases. Finish, test, and document each phase before starting the next one.

Current stack:
Python, Flask, SQLite, HTML, CSS, and light JavaScript only when useful.

Current app status:
- Flask app is running with active routes for home, login/logout, ticket submission, employee lookup, admin queue, admin ticket detail, ticket conversation replies, and health check.
- Basic session login separates employee and admin navigation.
- Admin-only routes are protected.
- SQLite stores submitted tickets.
- Ticket numbers are generated automatically.
- A simulated employee directory can find sample employees by company email or employee ID.
- A local demo seed script can create sample tickets for screenshots and analytics testing.
- A local notification-log seed script can refresh sample Critical alert logs for dashboard review.
- Employees can submit tickets and look up tickets by ticket number, email, or both.
- Employee ticket number lookup shows full details, while email-only lookup shows a compact ticket list.
- Admins can view tickets in a queue, open ticket details, update triage fields, and review basic metrics.
- The admin dashboard is separated from the full ticket queue to keep the overview page clean.
- Admins can search and filter the ticket queue by keyword, status, priority, issue type, and assignee.
- Admin search results update live while typing or changing filters, with Apply Filters kept as a fallback.
- Admins can choose how many queue tickets to view at a time: 10, 25, 50, or 100.
- Admins can review analytics for resolution time, issue mix, assignee workload, and priority mix.
- Admins can add private internal IT notes to individual tickets.
- Admins and employees can add employee-visible ticket conversation replies.
- Smart priority suggestion is rule-based and currently used as a triage aid.
- Critical smart-suggested tickets are visually marked in the admin queue.
- Rule-detected Critical tickets create simulated admin email notification log entries.
- The admin dashboard shows only recent Critical alert logs to avoid flooding the main page.
- Admins can open a full Critical Alert Log page with search and filters.
- The Critical priority filter includes both IT Critical and Smart Critical tickets.
- Visible timestamps are shortened to date plus hour and minute.
